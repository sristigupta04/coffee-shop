# ☕ Coffee Shop

A modern full-stack Coffee Shop web application built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Prisma**. This project is currently under development and focuses on creating a clean, responsive, and scalable online coffee ordering experience.

> 🚧 **Project Status:** Ongoing Development

---

## ✨ Features (Completed)

* Responsive UI
* Home Page
* Coffee Menu
* Reusable Components
* Product Cards
* Category Filtering
* Shopping Cart UI
* Login UI
* Register UI
* Checkout Page UI
* Order Summary Component
* Address & Payment Form
* Navbar & Footer
* TypeScript Integration
* Tailwind CSS Styling
